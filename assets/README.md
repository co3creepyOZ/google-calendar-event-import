# App icon

`app-icon.png` is used by the Electron window, page favicon, and app header.
Generated with the built-in image generation tool. Keep this asset with the source distribution.

## Generation prompt

Use case: logo-brand. Asset type: production Windows desktop app icon for a school timetable to calendar importer. Generate one square icon: a deep navy rounded-square tile with a crisp ivory calendar page, two simple binding tabs, a few large timetable squares and a prominent mint-green checkmark integrated in the lower right. Sophisticated restrained soft 3D depth, bold clean silhouette, excellent legibility at 32px, centered front view, nearly fills canvas with 6% transparent outer margin. Palette navy #152940, emerald #08765c, mint #62e3c0, ivory. No text, letters, numbers, Google logo, watermark, scenery, or extra objects. True transparent background outside the rounded tile.
