01

Додайте розклад

Де взяти посилання на розклад?
  1. Відкрийте client.rozklad.org ↗ та знайдіть свою школу.
  2. Відкрийте сторінку розкладу вашої школи та скопіюйте її повне посилання з адресного рядка — не адресу головної сторінки.
  3. Вставте посилання нижче й натисніть «Завантажити». Оберіть вчителя або клас, за потреби налаштуйте групи та створіть перегляд.

Посилання й вибір зберігаються на цьому пристрої.

Групи для календарних подій

Для вчителя: при накладанні уроків звіряє предмет, вчителя, групу та варіант у розкладі класу. Якщо клас теж містить декілька варіантів, оберіть групу вручну. A/B не визначаються автоматично за номером тижня.

Вибрана група застосовується до всіх уроків. Спільні уроки без поділу на групи залишаються. «Не включати» пропускає урок повністю. A/B — окремі позначки розкладу, а не номери груп.

Налаштувати окремі уроки

Вибір зберігається окремо для сторінки, вчителя або класу та року. Персональні налаштування уроків мають пріоритет над загальним вибором.

Дати беруться зі сторінки; рік і час дзвінків — із налаштувань. Варіанти A/B зберігаються як позначені на сайті: перевірте їх перед експортом.

Як підготувати Markdown або файл .md?
  1. Встановіть Obsidian Web Clipper для Google Chrome ↗.
  2. На client.rozklad.org ↗ знайдіть свою школу та відкрийте потрібний розклад вчителя або класу.
  3. За допомогою розширення скопіюйте вміст сторінки як Markdown або збережіть його в Obsidian як файл .md.
  4. Вставте Markdown у поле нижче або натисніть «Відкрити .md» та оберіть збережений файл.

Збережіть заголовки днів, дати та всі таблиці, навіть порожні: вони визначають порядок днів. Перед створенням подій перевірте рік і дзвінки в налаштуваннях.

Вставте весь кліпінг разом із днями та датами. Порожня таблиця означає день без уроків.

Налаштування року та дзвінків

Для дат без зазначеного року.

Стандартно: уроки 45 хв, перерви 10 / 10 / 20 / 10 / 10 / 10 / 10 хв. Перевірте час за вашим розкладом дзвінків.

Зберігає рік, дзвінки, кольори та сповіщення на цьому пристрої.

Для сповіщень завантажте ICS. CSV не підтримує сповіщення. «Без сповіщення» не додає нагадування у файл; перевірте також стандартні сповіщення календаря Google.

Не вдалося визначити активний урок

Натисніть на потрібний варіант уроку: активним може бути лише один. Повторне натискання або «Очистити вибір» скасовує вибір — тоді буде включено обидві події. Вибір діє лише для поточної генерації.

Google Calendar Sync — без Desktop OAuth JSON

Особисте підключення через Google Apps Script. Синхронізація запускається кнопкою: розклад у програмі → ваш календар Google.

Як підключити Apps Script
  1. Відкрийте script.google.com у браузері під потрібним Google-акаунтом і створіть новий проєкт.
  2. Натисніть «Показати код» нижче. Скопіюйте весь код у файл Code.gs вашого проєкту та збережіть.
  3. У редакторі Apps Script виберіть Services → + → Google Calendar API → Add (ідентифікатор Calendar). Якщо використовується власний Cloud-проєкт, увімкніть Calendar API також у ньому.
  4. Запустіть функцію setup та надайте доступ до календаря. У журналі виконання з’явиться приватний connection key. Скопіюйте його. Ключ не передавайте іншим.
  5. За замовчуванням використовується основний календар. Для іншого календаря в Project Settings → Script Properties змініть CALENDAR_ID на його ID із налаштувань Google Calendar та повторіть setup.
  6. Deploy → New deployment → Web app: Execute as — Me, Who has access — Anyone. Розгорніть і скопіюйте URL, який закінчується на /exec. Якщо організація забороняє Anyone, цей спосіб недоступний без дозволу адміністратора.
  7. Вставте URL і ключ нижче, натисніть «Підключити». Перевірте назву календаря та часовий пояс. Згенеруйте уроки й натисніть «Синхронізувати уроки».

Доступ до вебзастосунку публічний, але запити перевіряються приватним ключем, підписом і часом запиту. Ключ надає право створювати та оновлювати уроки в обраному календарі. Для іншого користувача потрібен окремий проєкт, розгортання й ключ.

Ідентичність уроку: дата + номер уроку + клас/група. Зміни часу, предмета, кабінету, кольору та сповіщень оновлюють подію. Зміна дати, номера або групи створює іншу подію; попередня не видаляється. Події з CSV/ICS або попереднього OAuth-експорту не пов’язуються автоматично. Правки в Google не завантажуються назад.

«Відключити» видаляє локальні збережені URL і ключ. Для відкликання доступу також архівуйте розгортання в Google або змініть SYNC_KEY. Після зміни коду створіть нову версію розгортання.

Apps Script не підключено.

Google Calendar — пряме створення подій (Desktop OAuth)

Завантажте OAuth JSON типу Desktop app, увійдіть у Google та виберіть календар. Перше підключення? Розгорніть інструкцію нижче.

Як підключити Google Calendar — покрокова інструкція
  1. Відкрийте Google Cloud Console у браузері (console.cloud.google.com). Створіть або виберіть проєкт і ввімкніть Google Calendar API.
  2. Налаштуйте Google Auth Platform / OAuth consent. Якщо тип застосунку — External зі статусом Testing, додайте свою адресу Google до Test users.
  3. Створіть клієнт OAuth типу Desktop app (не Web application). Завантажте його JSON-файл.
  4. У цьому блоці натисніть «Завантажити OAuth JSON» та виберіть завантажений файл.
  5. Натисніть «Увійти в Google». Завершіть вхід і надайте доступ у браузері, потім поверніться до програми. Час очікування — 3 хвилини.
  6. Згенеруйте й перевірте уроки. Виберіть календар призначення та натисніть «Створити події в Google Calendar». У вікні підтвердження перевірте назву календаря, кількість подій і часовий пояс.

Кольори, час і сповіщення

Колір кожного класу наближається до найближчого кольору палітри Google. Час уроків використовує часовий пояс вибраного календаря. Налаштування сповіщень замінюють стандартні нагадування календаря, включно з варіантом «Без сповіщення».

Повторне створення

Ідентичні події, створені цією програмою, пропускаються під час повторної спроби. Зміна назви, дати, часу, кабінету або календаря створює нову подію, а не оновлює стару. Події, раніше імпортовані через CSV або ICS, не розпізнаються — не імпортуйте той самий розклад двічі.

Доступ до облікового запису

Облікові дані та токени зберігаються локально із шифруванням Windows. Кнопка «Вийти» видаляє файл підключення Google, токени та OAuth client ID / secret з пам’яті програми. Для наступного входу завантажте OAuth JSON знову. Вихід не видаляє оригінальний завантажений JSON, події Google або налаштування уроків. Щоб також відкликати доступ у Google, видаліть застосунок у розділі сторонніх підключень свого облікового запису Google.

Якщо не вдається підключитися

  • Перевірте, що Calendar API ввімкнено, а OAuth-клієнт має тип Desktop app.
  • Для статусу Testing перевірте свою адресу в Test users. Може знадобитися повторна згода через 7 днів.
  • Якщо минули 3 хвилини, натисніть «Увійти в Google» ще раз.
  • Для шкільного облікового запису політика організації може вимагати дозволу адміністратора.

Час використовує часовий пояс вибраного календаря. Кольори наближаються до палітри Google; «Без сповіщення» вимикає нагадування. Повторне створення пропускає ідентичні події, але не оновлює їх.
